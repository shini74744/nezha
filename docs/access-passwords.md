# 前后台访问密码

管理员在 **个人资料 → 更新个人资料下方 → 访问密码** 管理全站访问密码。普通用户不会看到此设置。原通用设置页不再显示前台密码。

- 前台访问密码控制监控前台，与原有账号登录密码独立。
- 后台访问密码是管理页面的额外验证，验证通过后仍需原有账号登录。部署升级不会自动设置或启用密码。
- 前后台验证页面复用同一模板，支持手机、电脑及系统深浅色。后台页面仅保留标题、密码输入及继续登录按钮；错误、封禁等必要反馈仍显示。
- 留空保留现有密码；勾选对应的“清除并关闭”才会关闭。新密码需确认，最多 72 UTF-8 字节。
- 后台错误次数默认 1 次，可设置 1–100 次；封禁默认 15 分钟，可设置 1–10080 分钟。
- 错误次数按客户端 IP 连续累计，15 分钟无尝试重置未达到阈值的计数。达到阈值立即封禁，重复访问不会延长封禁。
- 封禁只影响后台页面和浏览器管理 API；前台、Agent RPC 和已经通过正常鉴权的 PAT 集成不受此封禁影响。共用公网 IP 的浏览器会一起被限制。
- 后台验证 Cookie 为 HttpOnly、SameSite=Lax，有效 8 小时，绑定 IP、当前密码及签名密钥。更换密码使旧验证失效，同时使旧密码对应的错误/封禁状态失效。保存新密码的浏览器会立即获得新验证。
- 密码仅存 bcrypt 哈希，不向浏览器回传。错误/封禁保存在 SQLite 独立的 backend_access_attempts 表内，重启不会解除未到期封禁。
- 客户端 IP 沿用面板的真实 IP 配置；未配置时仅回退到 TCP 对端，不额外信任任意 X-Forwarded-For。反向代理部署需要正确配置可信入口和来源限制。

## 独立设置 API

管理员浏览器使用 GET/PATCH /api/v1/setting/access-passwords，保留既有 CSRF 校验，禁止 PAT 调整此安全设置。PATCH 只更新指定访问密码字段，不覆盖站点、主题、Agent 密钥等其他设置。配置落盘失败会回滚内存值。

账号登录和只读身份/刷新接口为前后台共用；后台密码不是替代账号鉴权。绕过后台页面直接调用管理 API 仍需后台访问验证。

## 排障

退出账号、关闭标签页或重新打开后台，不会自动清除仍有效的 HttpOnly 后台访问验证 Cookie；账号登录和访问验证是两层独立状态。因此保存密码的当前浏览器可能直接进入账号登录页，而手机或新浏览器仍需验证。需要核对全新访问时，可使用无痕窗口；不要用故意输错密码测试线上封禁。更换密码、IP 变化或验证到期后需重新验证。

封禁页面会提示等待时间；到期后刷新重新验证。忘记后台访问密码时，可由服务器管理员在备份 config.yaml 后清除 backend_password_hash 并重启面板；此操作不会改变原有账号密码。不要公开配置文件或哈希。

## 验证

Go 测试覆盖阈值、正确密码重置、到期、Cookie/密码轮换、IP 隔离、并发、SQLite 持久化、CSRF、失败关闭、管理员权限与设置保存回滚。Playwright 使用隔离配置和虚拟账号，不修改线上密码；真实 Go 验证处理器仅监听构建机 loopback，用于验证浏览器提交、后台封禁和前台不受影响。

## 展开设置与每日验证时段

访问密码卡片默认收起，只显示前台、后台的启用状态或验证时段。“展开设置”后修改；有未保存修改时按钮变为“取消修改”，收起会丢弃草稿，失败保存则保留草稿供重试。

前台、后台各自可选择“仅在指定时间段验证”。关闭定时选项是全天验证，不是关闭密码。必须已设置对应访问密码，时间段才会生效。升级默认不启用定时，也不会修改线上现有密码。

- 每天按北京时间（UTC+8）计算，与服务器操作系统时区无关。
- 开始时刻包含，结束时刻不包含；例如 08:00–23:00 在 23:00 起免验证。
- 结束早于开始表示跨午夜，例如 22:00–07:00（次日）。不允许开始、结束相同。
- 时段外免“访问密码”验证；后台原有账号登录和权限检查始终保留。已有后台 IP 封禁仍按原到期时间解除。
- 每次新页面/API 请求按服务端时间判断，不需要重启。已通过密码验证且仍有效的凭证继续有效，不会在每日时段开始时强制重复输入；既有长连接不主动断开。
- 免验证期间不会签发访问密码 Cookie，也不累计密码失败次数，避免免验证凭证在保护时段继续通行。
- PATCH 字段：frontend_password_schedule、backend_password_schedule，各含 enabled、start、end（HH:mm）。只修改一端不影响另一端；配置中非法时段按全天验证处理，避免配置错误导致放行。

新增测试包含时区/午夜/秒级边界、配置持久化和回滚、免验证不签发凭证、封禁跨时段、实际二进制路由，以及 320/390/768/1024/1440 宽度的深浅色浏览器交互。
