Agent 批量可视化配置（custom-2026.10.11.8-ali 试用）

入口：服务器列表勾选节点后，点击黄色齿轮“批量配置 Agent”。单个服务器操作列的配置入口保持不变。
常用配置按监控采集、上报频率、更新设置、远程功能、网络设置分组，支持中文或参数名搜索。
默认全部“不修改”；勾选后的值是本次准备设置的值，不是节点当前值。只发送选中的字段，取消勾选即从请求移除。
使用中文开关、数值单位与范围校验、多行路径及网址输入、网卡行编辑，用户无需手写 JSON。
布尔开关以“允许/开启”表述，代码将 disable_* / skip_* 参数反向转换，避免开启和禁用混淆。
网卡 map 按名称合并更新；非空名单仅采集标记为 true 的网卡。空列表下发 null 以清空原 map，恢复自动识别。磁盘、DNS、IP 查询列表为空时下发 []。
提交分为“检查改动”和“确认下发”；冻结打开弹窗时选中的系统 ID，显示中文改动列表与目标 ID，不混淆排序 ID。
关闭命令执行会同时禁用网页终端、文件管理及远程配置，须明确确认风险；恢复需使用其他 SSH。本界面不批量修改面板地址、客户端密钥、TLS 或 UUID。
失败保留草稿，不自动重试；提交中防重复。响应分别展示已下发、失败、离线，不将“任务已发送”误称为“节点已应用”。离线节点不补发。
弹窗主体独立滚动、底部操作固定，手机不自动弹出输入键盘。明暗主题遵循后台现有样式。
本次仅部署阿里；不实际修改任何线上节点 Agent 参数，不发布 GitHub。
