# 美化与图标设置

后台「美化设置」「后台美化设置」「图标设置」仅限管理员使用。

## 编辑和保存

- 美化设置支持按名称、说明和字段名称搜索，以及按品牌、布局、数据、特效分类。
- 折叠设置首次展开时加载控件。收起、搜索或切换分类保留当前草稿。
- 每项的「恢复本项默认」仅重置该项；背景和对应声音控制作为一项恢复。重置后仍需保存。
- 「撤销本次修改」恢复到本次读取或最近成功保存的设置。
- 保存期间锁定编辑，避免响应覆盖期间输入的新内容；失败后保留草稿。
- 页面内切换和浏览器返回会询问是否放弃未保存修改。刷新或关闭浏览器使用浏览器原生提醒。
- 登录过期时仍按登录流程处理，不被草稿提醒拦住。
- 全站显示的两个独立开关仍然自动保存，与主题外观的手动保存互不影响。
- 其他页面修改造成版本冲突时，重新读取后再保存，不覆盖别人的更改。

## 预览与后台外观

展开外观预览后，可选择电脑、手机、浅色和深色。预览使用示例服务器，展示布局、品牌、基础背景、字体及数据样式；并非当前服务器数据。后台额外展示卡片、菜单和导航透明度。

预览使用隔离文档，不改变当前页面的主题、设置或浏览器存储，不加载自定义脚本、统计分析、登录接口或实时服务器连接。图片仍需网络可用。分时背景、联网内容和动态特效以保存后的实际页面为准。

后台不透明度以 0–100% 显示，保存值仍为原来的 0–1；背景选项改用中文名称。动画小人的开关直接表示显示或隐藏。旧标题兼容字段保留在配置中，不再作为普通编辑项显示。

## 图标库

- 每个图标显示关联服务器数量。修改前可展开关联服务器列表，保存后继续同步已有引用。
- 浅色和深色底板并排预览，便于检查透明图标的可读性。
- 修改图标或分组时，关闭、取消、Esc、点击弹窗外部都会保护未保存修改。
- 厂商图标可勾选后批量移动分组；本页全选只选择当前页。切换筛选会清空选择，翻页保留选择。
- 每次最多移动 500 项。批量请求校验每项版本，任意一项已修改、被删除或不属于厂商时，整批回滚。
- 分组操作不改服务器配置、图标快照或业务数据。

## 管理接口

均要求管理员身份，API 令牌还要求 `nezha:admin:*`；沿用现有 CSRF 和认证保护。

- `GET /api/v1/logo/usage`：按图标 ID 返回关联服务器的 ID、名称；不返回备注、地址、凭证。
- `POST /api/v1/logo/batch-group`：请求示例：

```json
{
  "group_id": "group-example",
  "entries": [
    {"id": "provider-example", "version": 1}
  ]
}
```

`group_id` 为空字符串表示移到未分组。返回 `updated` 数量。只允许厂商图标，所有更新在同一事务中完成。
