# 首页账单显示

在「服务器 → 编辑服务器 → 账单信息」中，可按服务器独立设置：

- 金额行右侧的「显示金额」：控制价格、免费或按量付费文字。
- 周期行右侧的「显示剩余天数」：控制剩余天数、永久／已过期提示，以及对应的剩余时间进度条。

两项默认显示，可分别关闭或同时关闭。保存后前台随服务器信息更新生效，默认、纸张和哆啦 A 梦主题均支持，电脑端与手机端一致。

开关仅控制显示，不删除金额或日期，也不改变续费、套餐或流量统计规则；隐藏不是数据访问权限控制。

配置保存在公开备注 `billingDataMod.showPrice` 和 `billingDataMod.showExpiry` 中，`"1"` 显示，`"0"` 隐藏。旧配置未设置时默认显示。后台原始文本编辑支持「显示金额」「显示剩余天数」布尔值，并保留其他字段。
