# 检测次数与回程地图（2026-10-09）

## 检测口径

- 服务器：2 次预热 + 5 次正式 HTTPS 小资源检测；本地：2 次预热 + 10 次正式 HEAD 检测。
- 小点仅表示正式检测，每次有效响应加入当前平均值；超时和浏览器错误不是 0 ms，停止时保留已完成样本。
- 本地测量在独立 Web Worker 内计时，网页持续展示进度；Worker 无法启动或中断时可回退，重置该轮部分结果以避免混合样本。
- 并发、权限及单项重测边界不变。服务器整批预算 4 分钟，本地单项目预算覆盖 12 次请求。老记录不补造样本，新任务按新次数执行。
- 不保证与 ip.skk.moe 的数值一致；不同页面、连接、采样数量和网络状态会影响 HTTPS 请求耗时。

## 回程地图

- 详情标题旁增加“逐跳／地图”，默认逐跳；切换视图不发起网络探测。关闭后再次打开回到逐跳。
- 复用内置地图底图与 d3-geo，按需加载；无新增地图 API、密钥、瓦片服务或路由上传。
- 保存 NextTrace 原始 JSON 的有效经纬度。缺失、(0,0)、越界、私网地址和被隐藏地址的定位不绘制，不根据 IP 归属名称猜测坐标。
- 实线只连接相邻 TTL 且双方均唯一响应、定位有效的记录；虚线连接中间缺少定位、未响应或缺失记录的已知位置，仅表示顺序而非直接链路。多响应处不猜测分支。同位置合并，可点地图或跳点按钮查看详情。
- 按反馈移除地图上方的完整线路总览与重复技术提示，仅保留简短连线图例、折叠的未定位原因和定位免责声明。完整记录仍可在“逐跳”查看，不影响检测、到达状态或最终延迟。
- 新旧快照均直接使用新视图，无需重新检测、迁移或修改原始记录。旧快照没有坐标时显示空态与未定位原因，可切换逐跳查看；不是补造历史定位。地图数据为 NextTrace 回程，不混作 BGP AS 观测路径。
- 保持 IP 脱敏规则并同步移除隐藏节点坐标。地图不是机房或光缆的真实路径证明。
- “首个大陆响应”表示境外记录之后首次定位到大陆的响应，不确认入境位置。每跳延迟是独立往返时间，后续更低并非必然错误。
