# 检测次数与回程地图（2026-10-09）

## 检测口径

- 服务器：2 次预热 + 5 次正式 HTTPS 小资源检测；本地：2 次预热 + 10 次正式 HEAD 检测。
- 小点仅表示正式检测，每次有效响应加入当前平均值；超时和浏览器错误不是 0 ms，停止时保留已完成样本。
- 本地测量在独立 Web Worker 内计时，网页持续展示进度；Worker 无法启动或中断时可回退，重置该轮部分结果以避免混合样本。
- 并发、权限及单项重测边界不变。服务器整批预算 4 分钟，本地单项目预算覆盖 12 次请求。老记录不补造样本，新任务按新次数执行。
- 不保证与 ip.skk.moe 的数值一致；不同页面、连接、采样数量和网络状态会影响 HTTPS 请求耗时。

## 回程地图

- 详情标题旁增加“逐跳／地图”，默认逐跳；切换视图不发起网络探测。关闭后再次打开回到逐跳。
- 复用内置地图底图与 d3-geo，按需加载；无新增地图 API、密钥、瓦片服务或路由上传。
- 保存 NextTrace 原始 JSON 的有效经纬度。缺失、(0,0)、越界、私网地址和被隐藏地址的定位不绘制；旧快照无坐标时提示重新检测。
- 只连接相邻 TTL 且双方均唯一响应、定位有效的记录；缺失、未响应和多路径不补线。同位置合并，可点地图或跳点按钮查看详情。
- 保持 IP 脱敏规则并同步移除隐藏节点坐标。地图不是机房或光缆的真实路径证明。
- “首个大陆响应”表示境外记录之后首次定位到大陆的响应，不确认入境位置。每跳延迟是独立往返时间，后续更低并非必然错误。

## 发布验证

- 前端 94 个测试文件、941 项测试通过；后端全量测试、连通性／网络洞察竞态检查和 go vet 通过。
- 浏览器覆盖 338 项场景，包括两套主题、浅深色、320／390／768／1440 宽度。首轮 329 项通过，9 项受到旧的等待预算和瞬时轮询断言影响；仅修正测试脚本后，包含全部失败场景的 16 项复测通过。生产代码未因此变更。
- Linux、Windows、macOS 自动检查及 CodeQL 通过；正式 Linux／Windows 安装包通过原生生命周期测试，覆盖登录、加密命令、优雅重启、两次异常中断恢复、Agent 上报和 SQLite 完整性。
- 浏览器使用构建机 Chromium；手机为触摸／视口模拟，不等于实机 Safari 或用户本机 Edge 验证。公开域名的自动访问受到 Cloudflare 验证限制，部署后改用阿里源站验收，不将源站结果冒充该访问入口的验证。
- 二进制对应运行时代码提交 `0b1507a`；后续提交只调整上述测试和本验证说明。最终部署与下载校验结果见 `custom-2026.10.09.2` Release。
