# 磁盘读写与 BGP 紧凑标题验收（2026-10-08）

## 后续磁盘卡片交互调整

根据后续反馈移除重叠边缘，读取/写入标签改成固定列对齐，仅左上角标题按钮允许切换。卡片、曲线、数值不再是切换入口；在线和离线视图同步处理。标题按钮保持原生键盘操作和切换后的焦点；图表采用 200 ms 纯淡入，避免移动动画期间快速触控图表引发滚动变化，不禁用页面缩放。

完整前端 86 个文件、769 项测试及两套前端构建通过。标题点击专项与离线回归通过；1440/1024/768/390/320 px 明暗主题、1440/390/320 px 离线视图通过浏览器验收：固定 194 px 高度、标签坐标不随不同长度速率变化、没有横向溢出，点击数值/曲线不切换。快速触控专项确认纯淡入后不再触发动画期间的滚动变化。

本次只涉及前端组件及测试，不修改 Agent、上报协议、数据库或生产配置。下文记录的是前一版完整采集链路及最初 UI 的验收，当前交互以 [磁盘读写说明](disk-io.md) 为准。

## 本次变更

- 磁盘卡片默认显示容量，点击、触屏轻触或 Enter/空格才切换读写速率；不因悬停、实时上报或历史周期变化自动切换。
- 同一张卡片固定高度，200 ms 轻微淡入，尊重系统减少动态效果；卡片后方增加一层左右内缩、向上露出 6 px 的重叠边缘。
- Agent 采集操作系统设备字节计数，按实际时间差计算读写速率；追加兼容协议字段、快照与历史指标。无采样能力时保留未知，不伪造零值。
- BGP 协议、网段、路径数移入标题区域，宽屏同行，窄屏换行，移除原空行；不改变可见权限及快照行为。

采样口径、旧 Agent 兼容和历史边界见 [磁盘读写说明](disk-io.md)。
