# 磁盘读写与 BGP 紧凑标题

## 磁盘卡片

- 进入详情默认显示磁盘占用、已用/总容量。卡片采用单层显示，不保留后方重叠边缘。
- 仅点击或手机轻触左上角“磁盘 / 磁盘读写”标题按钮切换，再次点击切回。点击曲线、读写数值或卡片空白处不切换；鼠标悬停、实时上报、选择历史周期也不会自动切换。
- 读取和写入使用固定宽度的两列布局，标签上下对齐且位置固定，右侧数值使用等宽数字更新，不带动文字跳动。
- 标题按钮支持 Enter / 空格，切换后保留键盘焦点。固定图表高度，图表切换使用 200 ms 轻微淡入；系统开启减少动态效果时关闭动画。
- 实时、历史查询和离线最后上报均支持读写数据。历史周期沿用现有访客/登录权限及 TSDB 保留策略。
- 老 Agent、采样预热或系统不支持读写计数时显示暂无数据，不伪造零速率；真正空闲时显示 0。

## 采样含义

需要自有 Agent **v2.3.8 或更新版本**。仅更新面板不会让旧 Agent 自动具备采集能力。

读写速率以两次操作系统累计字节计数的差值除以实际采样间隔计算，单位为 Bytes/s，界面转换为 KiB/s、MiB/s 等。表示整台机器的块设备吞吐量，不是磁盘占用变化，也不是某个进程、目录或仅已挂载文件系统的速率。

Linux 仅汇总完整的底层块设备，排除分区、loop/ram/zram 及有底层设备的堆叠映射，避免同一次 I/O 在分区、LVM/RAID 层重复计算。计数器复位、设备增删和读取失败会重新建立基线，防止异常大数。其他系统使用 gopsutil 提供的设备计数；没有可用计数时保留未知状态。

协议兼容新增字段：State 19 disk_read_speed、20 disk_write_speed、21 disk_io_available。旧字段编号不变；旧面板忽略新增字段，旧 Agent 在新面板上仍正常上报其余指标。

历史接口在现有 GET /api/v1/server/:id/metrics 中新增 disk_read_speed、disk_write_speed；没有有效采样时不写入这两类指标。旧历史无法追溯补采。

## BGP

桌面宽屏中，IP 协议、网段及观测路径数与 BGP 路由拓扑标题放在同一行，去掉原独立行的空白。窄屏自动换行，避免挤压标题和重新检测按钮。原有 IP 可见权限、协议筛选及快照切换行为保持不变。
