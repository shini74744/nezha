# 首页网卡统计

适用于主面板 v0.0.20 和 Agent v1.0.9。

在后台节点齿轮中展开“首页显示网卡”，勾选一个或多个已监控的网卡，点击“保存首页设置”。“全部”恢复原有监控范围；此设置独立于 Agent 的“监控网卡”，不会修改业务网络或其他采样设置。

- 两个主题的首页上传、下载速率及累计／套餐周期流量均使用所选网卡合计。
- 管理员打开详情时默认使用后台选择；可临时切换单个网卡、全部或所选合计。“详细查看”同步切换，临时查看不修改后台保存值。游客不显示网卡选择入口。
- 网卡暂时消失、机器离线或重启不会清除首页选择。缺失数据显示为空缺，不以其他网卡替代。
- 单网卡累计计数需要支持该协议的新 Agent；旧版本仍可使用原合计，选择旧 Agent 无法提供的字段时显示暂无数据。
- 周期流量从收到单网卡计数后累计，不能用旧合计历史反推。记录不足或出现计数重置时标明不完整／估算；更改周期重置日仍采用北京时间并正确处理月末。
- 选择物理口和其上的桥接、拨号等网卡时，同一流量可能被重复计数，请按业务选择需要的层级。
