# 默认首页地图与玻璃反光验证

本次改动仅涉及默认前台界面。地图继续使用原有地理数据与服务器状态；没有新增地理查询、修改 Agent、服务器设置或业务网络。

## 使用方式

地图显示区域分布、节点总数和在线数。底部区域按钮和右侧区域概览已移除。悬停地图可查看信息，点击区域保留详情浮层；点击服务器进入详情，可关闭浮层或点地图空白处退出。手机端点击区域后在地图下方显示临时详情。服务器数据更新时，选中区域与悬停提示同步更新；所选区域消失后关闭详情。

普通及列表服务器卡片的玻璃亮部随鼠标在卡片内部移动，离开淡出。反光裁剪到卡片圆角内，位于内容下方且不拦截点击。触屏与系统“减少动态效果”模式关闭反光；减少动态效果时地图提示仍正常显示。
