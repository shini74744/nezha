# 后台选择监控网卡

在管理后台“服务器”列表中，点击单台服务器的齿轮“配置”，找到“监控网卡”。

支持网卡识别的 Agent 会在读取配置时返回当前可见的网卡列表。列表显示名称、启用状态，以及可读取到的类型和速率。Linux 可识别设备网卡、网桥、VLAN、拨号、聚合、隧道等接口；其他平台仍提供采集器实际使用的网卡名称，不确定的类型显示为“网络接口”。列表不进入其他网络命名空间，也不探测网络或修改接口。

- **默认行为保持不变。** 未配置白名单时继续使用原有名称排除规则，并非只统计物理网口。打开配置窗口、读取列表、取消窗口都不会改变统计范围。
- 已有手动名单按原设置显示；暂未检测到的已配置网卡保留在列表中，避免网卡暂时断开导致配置丢失。
- 勾选调整后，点击“提交”才下发到当前服务器。界面会为取消勾选的已有接口明确写入 `false`，兼容 Agent 的配置合并行为。
- 全部取消勾选表示不累计网络速度和流量；不会用空对象意外恢复默认。
- “恢复默认”提交 `nic_allowlist: null`，清除手动名单并恢复原有筛选规则。
- 同一路径的设备网卡、网桥、VLAN 或 PPP 同时计入时，可能重复统计；列表给出提示，但不替用户更改选择。历史记录不会因此自动重算。
- 原有批量配置仍按填写的接口名称操作，不会把一台机器检测到的网卡自动套用到其他机器。

## 兼容性与发布

自动列表从主面板 v0.0.15 与 Agent v1.0.5 开始提供，需要配套更新；只更新面板时，旧 Agent 保留“输入网卡名称 + 勾选”的入口，不再要求手写 JSON。枚举失败时保留原配置并提示，可手动填写。没有发布新二进制时，线上旧版本不会获得自动列表。

后端沿用已有的配置查询接口、服务器权限检查及 Agent 禁用远程配置限制，不新增公开接口。查询结果增加只读 `network_interfaces` 元数据，包含可用状态和接口列表；该字段不属于 AgentConfig，不写入配置文件，也不随前端表单提交。旧面板、旧 Agent 的配置字段格式保持兼容。

## 验证范围

测试覆盖原默认筛选不变、指定名单、全部取消、恢复默认、旧 Agent、枚举失败、配置中暂不存在的接口、取消与重新打开、迟到响应，以及手机/桌面和明暗主题。测试使用本地构建环境与模拟面板接口，不连接或更改生产节点。
