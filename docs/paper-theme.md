# 纸间 · Paper

纸间是独立的前台主题，采用纸张纤维纹理、叠层书页、装订边线、章节页码、印章与书签式控件。概览使用账页分栏，卡片、标签、地图、图表和弹窗统一为纸面与墨色；默认插画是本地绘制的书本和羽毛笔。浅色适合日间阅读，深色保留相同层次。页面装饰不会覆盖按钮或阻止触控。

## 启用与设置

- 后台「系统设置 → 前台主题」选择 **纸间 · Paper**，保存后前台切换到纸张主题。
- 后台「美化设置 → 设置主题」选择 **纸间 · Paper**，修改并保存它的独立美化设置。
- 在美化页选择主题只改变当前编辑对象，不会切换线上前台。
- 默认主题、纸间和哆啦 A 梦分别保存外观；切换主题不改服务器配置、网卡选择、监控数据或 Agent。
- 纸间默认关闭背景视频、粒子、字体覆盖等装饰，保留纸面显示。需要时可单独开启。原主题自定义代码不自动注入纸间。

## 页面范围

首页的概览、卡片、行列表、状态筛选、分组、排序、搜索、地图与统计入口，节点详情、实时与历史图表、网卡切换、在线记录、网络检测及其弹窗，均复用原生数据和权限逻辑。地图、图表、菜单、提示和前台访问密码页使用纸张配色。后台管理界面保持独立样式。

首页卡片默认显示累计上传和下载，不依赖旧主题的自定义脚本开关；如在纸间品牌设置中关闭总流量显示，则按该设置隐藏。后台指定首页网卡后，首页速率和累计流量遵循相同统计范围；详情可临时切换网卡查看。

纸间使用独立的背景缓存，不读取或清除默认主题保存的背景。鼠标玻璃反光在纸间不运行。图表依赖随主题打包，减少单独加载的脚本；未读取到数据和请求失败仍分别显示状态，不能用零值替代。

## 字体与效果

默认主题和纸间提供相同的原生美化选项：

- **字体**：按名称选择内置字体，支持随机、添加、编辑、删除、调整顺序及隔离预览。自定义字体支持 HTTP/HTTPS 字体文件，格式为 WOFF2、WOFF、TTF、OTF；文件服务器需允许跨域加载。也可指定访客设备上的本地字体；缺少字体时回退系统字体。删除正在使用的字体后恢复随机，至少保留一项。
- **点击爱心**：大小、持续时间、上浮距离、随机或固定颜色。
- **页面樱花**：电脑／手机数量、大小、速度、风向与风速、不透明度。
- **鼠标星星**：大小、持续时间、生成间隔、下落与横向距离、颜色列表。仅鼠标设备生成。
- **顶部链接样式**：字号、间距、不透明度、文字颜色、登录入口颜色、悬停颜色／下划线／上移。颜色留空时跟随主题。
- **隐藏顶部按钮**：支持隐藏登录入口，电脑和手机同时生效，不改变登录地址或身份验证。
- 顶部链接的文字和网址在「品牌与文字 → 站点品牌 → 顶部链接」编辑。

旧版本字体数字选项会对应原来的内置字体。保存时校验颜色、地址、数量和范围；特效采用数量上限和事件节流，关闭后清理动画与事件。设备启用“减少动态效果”时不生成这些粒子。

## 构建与配置

主题目录：`frontend/user/src/themes/paper`；构建命令：`npm run build:paper`，输出 `frontend/user/dist-paper`。
`script/build-paper.sh` 将产物放入 `cmd/dashboard/paper-dist`，随面板二进制嵌入。`script/fetch-frontends.sh` 对此主题调用本仓库的构建脚本。

外观接口：`/api/v1/setting/appearance?theme=paper-dist`，沿用管理员权限、版本校验和保存失败回滚。配置存放于 `paper_appearance_config`。前台设置接口只提供当前主题的外观，后台保存入口按主题隔离。

测试入口：
- 前后端兼容与参数：`appearance-options.test.ts`、`appearance_options_test.go`。
- 设置页保存／重载／主题隔离：`appearance-options.spec.ts`。
- 纸张页面、实时更新、地图、网卡、弹窗和多尺寸：`paper-theme.spec.ts`。
- 原生监控逻辑沿用现有前端回归测试，主题构建不需要升级 Agent。

### 铅笔手记外观

默认正文、标题和数字使用随主题打包的手写文楷，采用石墨色文字与低饱和度彩铅配色。上传为赭色、下载为灰蓝色；概览、卡片和网络图表保持一致。流量用量与资源进度仍区分正常、接近上限和超限，数据单位和统计规则不变。

纸面包含静态纤维纹理、横线、装订孔、页边与叠页阴影；卡片、统计栏、页签、详情图表、地图和弹窗使用同一套纸张样式。装饰不拦截点击，不增加持续动画。

字体为 LXGW WenKai 的重命名网页子集 **DDnezha Paper Hand**，遵循 SIL OFL 1.1；源码目录和发布包中的 `paper-font-OFL.txt` 保留授权。常用界面文字集中在首包，其余按 Unicode 范围按需加载，使用同站点资源与 `font-display:swap`。字体加载失败时仍能操作页面；后台显式选择的自定义字体优先。构建字体方法见 `frontend/user/scripts/build-paper-font.py`。
