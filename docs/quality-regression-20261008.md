## 验证入口

在仓库根目录使用 Go 1.26.8，Linux 构建开启 CGO：

```sh
go test -count=1 ./...
go test -count=1 -tags go_json ./...
go test -race -shuffle=on -count=1 ./...
go test -tags agentcompat -count=1 ./...
go vet ./...
gosec --exclude=G104,G115,G117,G203,G402,G703,G704 ./...
```

Agent 源码位置通过 `AGENT_SOURCE` 提供给工作流契约检查；启动真实进程的兼容性用例必须另外提供 `AGENTCOMPAT_NEZHA_SOURCE` 和 `AGENTCOMPAT_AGENT_SOURCE`。没有这些变量时出现 skip，不得算作已完成真实 Agent 压测。

用户端：lint、typecheck、全部 Vitest、默认主题与 doraemon 构建。管理端：lint、`tsc -b`、全部 Vitest、构建。浏览器回归使用隔离数据库及构建后的静态文件，生产数据不得作为可写测试夹具。带 `E2E_REAL_BACKEND` 的用例只能连明确的 localhost 隔离实例；持久化外观用例保存并还原初始配置。私有旧脚本迁移夹具通过 `LEGACY_APPEARANCE_FIXTURE` 传入，不能提交到仓库。

真实 Agent 夹具在自己的新建数据库中关闭自动公网探测，避免定时连通性/流媒体/BGP 任务污染压测的文件描述符和子进程基线；生产默认开关不变。SQLite 单次事务排空后，异步 MCP 审计仍可能提交，所以基线必须在 10 秒内取得完整、连续、无活动 journal 的采样窗口。窗口内仍拒绝任何活动 journal，不拼接样本、不修改资源阈值，不对资源增长失败重试；持续未排空必须失败。

文件权限拒绝用例校验 MCP typed failure、真实低权限 Agent 的 UID/GID，以及隔离数据库中对应节点的 Agent 错误审计；不能把控制器的同名权限拒绝当作 Agent RPC 证据。Windows 绝对路径和驱动器相对路径分别验证，保留零 HTTP 派发和目标文件哈希不变的要求。

桌面与手机尺寸覆盖不等于真实 iOS / Safari 设备验证。站点的浏览器 HTTP 耗时不等于 ICMP；解锁状态检查不等于账号实际播放测试。
