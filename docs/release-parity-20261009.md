## 本次在已部署基线之上的改动

1. 支持按住服务器行时用鼠标滚轮跨屏定位；松手只修改草稿，点击保存才写入。手机手柄拖动与普通列表滑动分开，保留箭头操作。
2. 修正静态检查发现的三处含原子字段结构体按值复制（批量设置一处、测试两处），采用索引取得指针，不改变批量设置的业务规则。
3. 发布文档与正式版本标识更新。前端构建包含 Git 提交标识，重新构建产生的新资源文件名不代表功能遗漏。

## 发布验收

发布前检查前台／后台单元测试、电脑与手机拖动操作、后端全量测试、静态检查和 GitHub 必需检查。Linux 和 Windows 均运行实际发布程序的启动、登录、数据落盘、重启与崩溃恢复测试；Windows 不以交叉编译成功代替原生执行测试。

正式资源包括 Linux／Windows ZIP、`version.txt`、自有 `nezha.sh`、systemd unit 和 `SHA256SUMS`。构建输入仅暂存在发布草稿，正式公开前删除。发布资源逐个核验文件大小与 SHA-256，阿里使用同一 Linux 程序并保留部署前备份。
