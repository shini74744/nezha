## 安装包与来源

- 正式程序版本和安装入口为 **v0.0.29**，包含 Linux x64 与 Windows x64 面板 ZIP。
- Linux 与 Windows 使用同一套经核验的前端资源和地区库输入；默认、纸间、哆啦 A 梦及后台资源与已部署版本逐文件核对。
- 正式版本号和发布文档会变化，因此正式程序的二进制哈希不要求与部署中的验证版本相同。功能代码与前端资源保持一致。
- `SOURCE_COMMIT.txt` 指向完整发布源码，`SHA256SUMS` 覆盖二进制压缩包、管理脚本和说明附件。
- Agent 源码和版本入口与 v0.0.28 相同，保持 **v1.0.11**；备份接收端及恢复工具保持 **v0.1.3**。
- 先验证草稿资产和平台测试，再公开 Release，最后更新 main 的面板版本入口；不改写既有 Release 或标签。

## 验证

功能提交已通过 30 项资源组件测试、20 个实际构建页面的浏览器场景，以及 8 档缩放像素检查。
浏览器场景覆盖三个主题、手机/电脑、明暗模式、连续小数颜色、动态更新及减少动态效果。
测试回放使用隔离的示例服务器，不等同于直接访问公开生产网址。

发布核验还包括前后台参数与编辑保护测试、Linux/Windows/macOS 源码测试、Linux 竞态和质量检查、
Linux/Windows 最终程序启动及生命周期检查、内嵌地区库检查、三个主题及后台资源哈希、下载后 ZIP 和 SHA-256 复核。
最终测试运行和产物核验记录随 Release 提供。
