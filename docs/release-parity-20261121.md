# DDnezha v0.0.30 发布对照

以 v0.0.29（75eee333）为基础，纳入已部署并通过验收的功能提交 9c33a1cca043206f809cf440cdd973b1eae781c4。
完整七项变化见 [功能说明](ddnezha-upstream-hardening-20261121.md)。

## 一致性

- 阿里面板验证版本为 v0.0.29+upstream.20261121.1；正式版使用 v0.0.30 版本标识。功能代码、前后台资源与地区库保持一致，版本标识不同会导致程序哈希不同。
- 原有网卡统计、流量周期、主题、美化、备份和 SSH 防护保留。
- 本版提供 Linux x64 和 Windows x64 面板包，使用同一套已校验的前端与真实 GeoIP 输入。
- Agent 源码、版本和发行附件保持 v1.0.11；备份接收端和恢复工具保持 v0.1.3。
- SOURCE_COMMIT.txt 标记发布源码；SHA256SUMS 覆盖面板包、管理脚本及文档附件。
- 发布包及版本入口验证完成后公开 Release 并更新 main，不改写原有正式版本。

## 验证

- 功能提交：Windows/Linux/macOS 全量源码测试、Linux 竞态和安全检查、Agent 兼容压力测试。
- 前端：71 个文件，486 项通过、2 项环境相关跳过；手机/电脑浏览器 8 项通过。
- 阿里上线验收：页面入口、实时 WebSocket、周期流量、在线历史和历史 CPU/网络查询；配置、服务器身份和 SSH 策略保持一致。
- 正式包：Linux/Windows 最终版本号程序的启动、停止、恢复、会话撤销、历史数据和内嵌资源校验。
- 最终 CI 链接、安装包校验及发布结果随 Release-validation.md 提供。

本轮 GitHub 发布不会再次重启阿里面板，也不升级服务器 Agent。上游版权和来源信息保留，产品名称和支持入口使用 DDnezha。
