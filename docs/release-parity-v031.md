# DDnezha v0.0.31 发布对照

以正式 v0.0.30（d1f1f154）为基础，纳入阿里已运行的功能提交 v0.0.31~1。

## 已纳入

- 飞机/Sakana 拖动按帧合并和指针捕获，预计算原弹簧轨迹，恢复持续回弹。
- 蜘蛛网相邻节点检索、独立线程绘制、同模块内置线程代码和分阶段初始化超时。
- 修复内部鼠标切换造成吸附中断，并验证设置变化、隐藏恢复、兼容回退和资源清理。
- 更新测试与使用说明。具体行为和测试范围见 [动画交互优化](animation-performance.md)。

## 源码和程序

- 阿里运行版本为 v0.0.30+network.20261121.2；GitHub 正式安装包标识为 v0.0.31。
- 正式发布仅增加版本入口及文档，应用功能代码和前端构建资源与阿里已验证版本一致。版本字符串不同，因此程序哈希不同。
- 提供 Linux x64、Windows x64 面板包；Windows 使用与 Linux 相同且经过哈希核对的前端和 GeoIP 输入，并原生运行正式二进制验收。
- SOURCE_COMMIT.txt 指向正式发布提交，SHA256SUMS 覆盖面板包、管理脚本及文档。临时构建输入在公开前移除。
- Agent 源码、版本入口、发行附件保持 v1.0.11；备份接收端和恢复工具保持 v0.1.3。
- 本轮仅同步 GitHub，不再次重启阿里，不升级服务器 Agent。
