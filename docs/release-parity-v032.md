# DDnezha v0.0.32 发布对照

以正式 v0.0.31 为基础，纳入已经部署到阿里的账单显示与服务器 IP 修复；功能来源提交为 v0.0.32~2。

## 本次变化

- 账单金额与剩余天数可分别显示或隐藏，默认均显示。开关位于金额和周期各自行右侧，保留原表单布局；隐藏剩余天数时同时隐藏对应的剩余时间条。
- 免费、按量付费、永久与过期提示遵循各自的显示开关；默认、纸间和哆啦 A 梦主题及手机端均适用。不删除日期或金额，不改变续费、套餐、流量计算。
- SSH 安全页支持按名称、ID、IPv4 和 IPv6 搜索，可输入部分地址，忽略大小写和首尾空格；离线节点按最后保存的地址匹配。
- 后台服务器列表在面板重启后仍显示离线节点最后上报的地址。已有运行期地址时整组优先使用它，不把旧 IPv6 拼到新的 IPv4-only 上报。
- 地址按 UUID 关联；新身份不继承旧节点 IP，从未上报的节点不生成地址。只批量读取最新地址，不读取整个历史列表，不改变在线状态或触发任何 Agent 操作。
- 原有账号与限定节点 API 令牌的访问范围不变。

## 源码与安装包

- 阿里已运行 v0.0.31+offlineip.20261122.1；正式 GitHub 安装包标识为 v0.0.32。
- 正式发布仅补充版本入口与文档，应用功能代码和前端资源与阿里已验证版本一致。版本标识不同会使程序哈希不同。
- 提供 Linux x64、Windows x64 面板安装包及 SHA-256 清单。Windows 原生构建使用与 Linux 相同且经过校验的前端与 GeoIP 输入。
- SOURCE_COMMIT.txt 标明准确发布提交，Release-validation.md 记录测试覆盖、限制及 CI 链接。
- Agent 保持 v1.0.11，备份接收端与恢复工具保持 v0.1.3。本轮只发布 GitHub，不再次部署阿里或升级节点。

使用方法见 [账单显示](billing-visibility.md)、[SSH 安全](ssh-security.md) 和 [离线 IP 与服务器历史](server-replacement-history.md#服务器列表的离线-ip)。
