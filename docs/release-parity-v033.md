# DDnezha v0.0.33 发布对照

本版纳入 v0.0.32 之后已在阿里部署的服务器服务选择、颜色及页脚优化，以及 IP 信息条透明度微调。

## 显示和交互

- 服务颜色默认由系统分配；服务器可选择专属服务、排序及颜色。没有选择时沿用默认范围，没有颜色覆盖时继承服务设置，安装命令复用不会清除面板绑定的设置。
- 网卡选择折叠显示，明确提示默认或已选择的数量。
- 桌面网络信息卡片居中并紧随页面内容，保持小间距；手机／平板隐藏，不保留空白位置。窄桌面窗口仍可使用。
- 默认主题的排序菜单、视图按钮及 IP 信息条使用明暗玻璃表面。IP 信息条底色不透明度为白天 62%、夜间 70%，文字透明度不变，纸张主题保留原有表面。
- 上传数据框使用淡暖色边框与底色，下载框保留原样。
- 网络图表提示框显示在页脚之上，并限制在视口内；列表超过高度时可以滚动，鼠标进入时保持，Escape 关闭。大量图例最多占 124px，可滚动查看。
- 本轮不修改用户背景配置或外部图片地址；随机背景源可用性仍由对应服务和访问网络决定。

## 发布与验证

Linux x64 与 Windows x64 面板采用相同前端及 GeoIP 输入。SOURCE_COMMIT.txt 标明来源，SHA256SUMS 提供附件校验；Release-validation.md 记录测试结果和 CI 链接。阿里更新同一正式版本。

配置、历史监控数据及服务器身份保留；本轮不升级 Agent，不启用或切换 SSH 防护。Agent 仍为 v1.0.11，备份接收端与恢复工具仍为 v0.1.3。
