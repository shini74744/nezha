# 换机安装与服务器信息历史

## 清理数据换机安装命令

在服务器「密钥」菜单选择“清理数据换机安装命令”，确认目标节点并勾选“清空全部旧历史和配置”，选择 Linux、macOS 或 Windows 后生成命令。普通新建节点也按安装命令的生成时间命名；复用同一条未使用命令保留原生成时间，已存在节点的普通重装或重连不会改名。复制或生成命令本身不清理数据；需在新机器执行，并成功上报主机信息和首次状态后才开始清理。

- 保留：内部系统 ID、UUID、显示顺序和所属账号；内部身份创建元数据不改。新机器使用新的独立密钥。
- 恢复默认：名称变为该次换机安装命令的生成时间（北京时间，格式如 `2026/10/19/00:00`），公开／私有备注、购买／到期日期、套餐、可见性、网络显示、DDNS 等节点配置全部清空或恢复新节点默认值。
- 清理历史：机器信息变更、操作记录（含公开备注前后全文）、信息基准、监控曲线、状态快照、流量及计费检查点、IP 简要历史、IPv4／IPv6 检测快照和缓存、终端会话／事件、到期通知发送记录、旧归属转移及节点审计记录。新上报建立全新基准，之后可以产生新的历史。
- 清理关联：该节点的分组归属、告警规则中的显式选择、IP 变更通知选择、计划任务／服务监控选择、NAT 及节点限定 API 令牌授权。令牌若仅授权该节点则撤销，避免空范围变为全权。
- 不删除共享对象：分组、通知渠道、全局告警／到期提醒策略、共享任务、DDNS 配置及其他节点不删除。覆盖“所有服务器”的规则仍按新节点生效；不是关闭全站通知。
- 这不是卸载或擦除旧服务器磁盘，也不主动删除远端 tmux 会话；清理的是面板内该节点的资料。已有数据库备份、已发送的外部通知仍按各自留存规则保留。清理后不能通过页面恢复旧资料。
- 流量：新机器首次累计上传／下载计数作为基准，之后只计新增量，不把新机器安装前的累计流量记入当前节点。
- 必须人工明确选择换机；CPU、IP、操作系统等信息变化本身不会触发清理。普通携带 UUID 的安装命令不会自动清除旧历史。
- 确认旧机器不再使用该 UUID；换机仍是一机一密，新机器使用该 UUID 绑定的新独立密钥，完成后旧密钥失效。本功能不是多台机器共用认证的方案。

v0.0.7 的接口必须提交 `confirmed: true` 和 `reset_scope: "full_node_v1"`；旧页面或旧版尚未使用的命令会要求刷新后重新确认，不能静默扩大删除权限。旧版已完成的凭据可继续重连；已进入清理的旧版任务按原先较小范围完成。

命令使用随机、限定节点与所属用户的专用凭据，首次使用须在两小时内；生成新待用命令会取代此前未使用命令。凭据仅存哈希，成功后可用于该 Agent 重连但不会重复清理。命令含敏感凭据，请勿公开或发给无关人员。服务器归属改变后旧凭据不能继续使用。

失败不会被显示为成功；已开始清理的节点会阻止旧状态继续写入，重连可继续完成。生产环境仍应先备份：监控数据库与业务配置不具备跨存储引擎的全局事务回滚保证。

## 主机信息更新

Agent 建立新连接并上报信息时，面板刷新 CPU、系统、内存、磁盘等主机信息，无需为更新显示而重启新机器。普通重连不清理历史；只有使用上面的专用换机命令才执行清理。自有 Agent 新系列保留此行为；当前 Agent 版本以 `release/agent-version.txt` 与正式 Release 为准，安装与升级见 [统一仓库说明](unified-repository.md)。

## 信息变化历史

服务器页“历史记录”先按当前显示顺序列出服务器卡片；已删除节点的历史排在当前节点之后。服务器每行操作区末尾的历史图标可直接进入该节点详情。

- 可按名称、原／当前系统 ID 查找，按操作类型及 CPU、内存、磁盘、系统、IP、区域、GPU 筛选。
- 详情展示修改前、修改后与日期时间。时间按浏览器设备时区显示，“检测到变化”是面板收到并记录信息的时间，不保证就是商家实际更换硬件的时刻。
- 首次建立基准显示“首次信息记录”，不会补造启用前未记录的变化。
- 磁盘容量为 Agent 上报的已挂载文件系统容量；不是原始块设备、未分配空间或实时磁盘使用变化。
- 默认长期保留，普通删除节点和系统 ID 重排不自动删除历史；历史中的当时名称和 ID 保留原样。例外是 v0.0.7 起明确确认的全量换机重置，它会清空该节点旧历史。
- 可确认删除单条整条记录，或清空该节点当前已确认范围内的历史。删除单条包含该条内其他字段；新产生的记录不在之前的清空确认范围内。删除历史不删除节点、监控曲线或信息基准。

### IP 记录中的双栈快照（主面板 v0.0.6）

一条 IP 变化记录同时显示 IPv4 和 IPv6 的修改前／后地址。另一协议族当次成功获取且未变化时标注“未变化”；它只作为上下文，不增加“变更项数”，也不会让记录匹配无关字段筛选。

当次未获取某协议族时，显示“本次未获取”；已有最近有效地址的会保留该地址并明确说明，不能据此认定该协议族当时可用。旧记录未保存的另一协议族显示“当时未记录”，不根据当前地址或其他记录猜测补齐。此功能不修改 IP 变更通知、最近 7 次 IP 简要历史或 Agent 检测周期。

### 查看公开配置／备注的修改前后内容

公开配置／备注发生修改时，在同一数据库事务中保存完整修改前、修改后文本，包括清空和长内容的修改。点击两侧“查看内容”分别打开只读详情；合法 JSON 缩进显示，其他内容按文本显示，HTML／脚本不会执行。仅修改该字段的记录保存对应内容；私有备注、DDNS 自定义域名及 Agent 凭据不在本次扩展范围内。

完整内容从安装包含本功能的面板后开始留存；阿里此前试用补丁生成的新记录同样可查看。旧版显示“内容不记录”的记录没有原文，按钮禁用，升级不补写、不改写旧历史。详情沿用管理员历史接口权限，不向访客开放。

公开配置／备注的历史原文会保留在数据库和备份中；不要在该公开字段填入密码、密钥或带签名的敏感地址。新增占用主要是每次真实修改的前后两份文本及少量 IP 快照、数据库元数据，随内容长度和修改次数增长，不按每次心跳重复保存。记录永久保留，仍仅按明确的历史删除操作清理。

电脑与手机使用同一套入口和筛选逻辑，窄屏换行并纵向滚动，沿用统一明暗主题和确认弹窗。
