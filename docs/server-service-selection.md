# 服务器服务选择与图表颜色

在后台“服务器 → 配置”的“首页显示网卡”后展开“服务选择”。

- 不选择任何服务：沿用服务页面的覆盖范围、全局排序和颜色。
- 选择服务：仅向这台服务器下发所选服务；选择列表可拖动排序，也可用上下按钮。服务所有者权限仍然有效。
- 默认颜色实时继承服务设置。只有手动改色时才保存单机覆盖；点击“恢复默认颜色”恢复继承。
- 点击“保存服务设置”单独保存，不会提交 Agent 配置或改变网卡设置。Agent 无需升级。
- 设置绑定服务器记录，普通安装命令复用、重连、升级、改名及面板重启均保留。删除服务器或执行明确确认的“清空记录重装”才清除。
- 删除最后一个已选服务不会自动放开全部探测：配置保留该 ID，待管理员移除或恢复默认。

服务页面支持 HEX 颜色选择。留空/“系统分配”在保存时分配当前服务中未使用的颜色；旧服务升级时补齐并持久化。手工指定可以使用相同颜色。

## API

管理员可使用：
- GET /api/v1/server/{id}/services：返回 services 和 available。
- PUT /api/v1/server/{id}/services：保存下面格式；services 必须提供，空数组恢复默认。

```json
{"services":[{"service_id":2},{"service_id":1,"color":"#884422"}]}
```

数组顺序为该服务器的显示顺序；未提供 color 或空字符串均继承。服务新增/编辑接口使用 chart_color：未提供字段时编辑保留旧值，空字符串请求分配新颜色，非空须为 #RRGGBB。

权限检查同时覆盖服务器、服务所有者以及受限接口令牌的服务器范围。保存失败不更新运行时配置。默认颜色迁移只处理服务元数据，不扫描历史监控表。
