# 服务器使用率颜色

首页的 CPU、内存、存储进度条按使用率连续计算颜色，替代原来的三档颜色。

- 0% 对应绿色，100% 对应红色，中间沿色相连续经过黄绿、黄色、橙色。
- 使用率的小数直接参与计算，不取整、不分档。
- 每次数据更新时，填充长度和颜色在 500 毫秒内平滑过渡；减少动画偏好关闭过渡。
- 数值限制在 0–100%；无效数值使用空进度。
- 默认主题、纸张主题和哆啦 A 梦的三项资源进度条使用同一计算方式；
  纸张主题只调整饱和度和明暗，保留纸面配色。
- 在线状态、流量额度和其他告警规则不变。

## 细条绘制与到期进度

资源和到期进度共用 4px 高的 SVG 组件，采用 crispEdges 对齐绘制边缘，避免半像素位置出现边缘模糊。绘制厚度按屏幕像素取整；所有细条共享一组缩放变化监听，无需滚动监听、逐帧测量或逐条 ResizeObserver。颜色和宽度保持 500 毫秒平滑过渡。

到期进度按剩余比例连续取色：100% 为绿，50% 为黄，0% 为红；保留小数，不分档。纸张主题沿用自身的饱和度和明暗，日期、计费周期和自动续期计算保持原样。
