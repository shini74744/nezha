# 服务显示排序

服务创建和编辑页面不再填写权重；ID 列只显示服务 ID。点击“服务排序”可以拖动、上下移动或输入指定位置，保存后更新后台及内置前台主题的服务顺序。关闭未保存的对话框不改变顺序。新服务追加到列表末尾，普通编辑保留原顺序。

排序使用 POST /api/v1/service/order，请求为 service_ids（新顺序）及 original_ids（打开对话框时的顺序）。必须提交有权限查看的完整列表；列表或顺序已变化时整体拒绝，前端保留草稿并提示重新打开。PAT 需要 nezha:service:write，继续遵循原有服务所有者和服务器范围限制。

后端以事务保存显示位置，再一次性发布新的运行时列表。排序不重建服务探测任务、不修改服务 ID、目标、间隔、覆盖范围或历史数据。公开服务统计附带 display_index，内置前台按其降序、同值按 ID 升序排列；旧版响应无此字段时按 ID 排列。
