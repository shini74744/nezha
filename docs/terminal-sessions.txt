后台终端：保持与 tmux（custom-2026.10.11.4-ali 试用）

1. 普通终端正在运行任务时，可点击右上角“保持”。按钮显示“已保持”后，关闭、刷新网页或客户端网络中断不会主动结束该 PTY。重新打开该节点，在“会话 > 原生保持”选择连接。一个原生终端同一时刻只允许一个网页连接，避免争抢输入。
2. 原生保持依赖面板进程、Agent 进程和两者之间的连接。面板／Agent 重启、节点重启、节点权限或账号令牌版本撤销均可能结束任务；不是持久化作业调度器。输出仅在内存保留最后 256 KiB，终端输入与输出不落数据库。
3. “会话 > tmux > 新建”输入会话名及首个窗口名。会话名最多 60 字，不含冒号、句点或控制字符。创建独立终端，不能把普通终端里已在运行的进程迁移进去。断开网页只断开 tmux 客户端；使用“结束”会终止该会话中的所有任务，须再次确认。
4. 页面显示 Agent 所用系统用户的默认 tmux socket 中的现有会话，包括其他 SSH 创建的会话。当前不枚举其他系统用户、自定义 -L/-S socket 或其他 TMUX_TMPDIR。点击窗口名切到该窗口；同一 tmux 会话的多个客户端共享窗口选择。不要假设节点／Agent 服务重启后仍存活：systemd 的进程组清理也可能结束 tmux 服务。
5. 数据库记录会话／窗口名称、创建或发现来源、节点 UUID、所属后台账号、创建和结束等操作。仅有数字服务器 ID 相同不能接回另一个节点的旧会话。刷新发现外部已结束的会话后隐藏；无网络或响应不完整时不误标为已结束。
6. 缺少 tmux 时点击“安装 tmux”，确认后在所选节点安装 tmux 和必要依赖；不批量安装、不执行整机升级。支持 apt-get、apk、dnf、yum、zypper、pacman，要求 root 和 timeout。最长等待约 5 分钟；关闭网页不会取消已下发的安装，可重新打开查看。失败会给出类别，不返回可能含软件源凭据的原始安装日志。失败或超时后先刷新核对，避免重复安装。
7. 后台新增接口仅接受登录会话；保留 CSRF、同源 WebSocket、用户与服务器权限检查。原生保持会话不向其他后台账号开放。tmux 的可见范围与该账号能够操作的服务器系统用户一致。当前不扩展到 TG 网页终端；TG 的一次性授权和连接限时维持原样。
8. 本次仅部署阿里，GitHub 源码／二进制未推送。数据库仅新增 terminal_sessions / terminal_session_events 两张表，不重置现有监控、账号、排序或通知数据。
