后台终端：面板保持与 tmux（custom-2026.10.11.6-ali 试用）

1. “面板保持”和“tmux 会话”是独立入口、独立列表。普通终端点击“保持当前”后才加入面板保持；创建或进入 tmux 不会自动保留旧普通终端，也不会生成面板保持记录。未开启保持时，切换前明确确认旧终端任务将结束；取消则不执行切换。
2. 取消保持成功后右侧列表立即移除该项，当前页面里的任务继续；随后关闭页面或断开连接，普通终端及任务结束。已在本页连接的当前会话点击“进入”只收起侧栏，不重复申请连接，断线后才恢复连接。面板保持依赖面板进程、Agent 进程和两者之间的连接。关闭或刷新浏览器后可从“面板保持”连接；同一个普通终端同一时刻只允许一个网页连接。面板／Agent 重启、节点重启、权限或令牌版本撤销均可能结束任务。输出仅在内存保留最后 256 KiB，终端输入与输出不落数据库。
3. “tmux 会话 > 新建”输入会话名及首个窗口名。会话名标识整组终端，窗口名标识其中第一个终端，默认 main。会话名最多 60 字，不含冒号、句点或控制字符。新建独立会话不能接管普通终端里已运行的任务。
4. 列出 Agent 所用系统用户默认 tmux socket 上的现有会话，包括其他 SSH 创建的会话。当前不枚举其他系统用户、自定义 -L/-S socket 或其他 TMUX_TMPDIR。点击窗口进入该窗口；同一会话的多个客户端共享窗口选择。节点／Agent 服务重启、systemd 进程组清理仍可能结束 tmux。
5. 网页终端初次进入默认展开快捷命令，可手动收起，与会话侧栏互斥。当前 tmux 会话提供“退出”：切换到普通终端并关闭本页 tmux 客户端连接，不调用结束接口、不删除会话，可再次连接。创建普通终端失败时保留当前 tmux 连接供重试。结束操作使用页面内确认弹窗，默认焦点在取消。结束当前面板保持或 tmux 会话后自动创建新的普通终端，不自动开启保持；结束其他会话不影响当前连接。自动新建失败可点“连接普通终端”重试；意外断线不自动新建，以免误解为恢复了原任务。
6. 数据库记录会话／窗口名称、创建或发现来源、节点 UUID、所属后台账号及操作历史。旧系统 ID 被复用不会接回另一节点旧会话；刷新发现已结束的会话后隐藏，网络错误时不误标为已结束。
7. 未安装时可确认安装 tmux 和必要依赖；不批量安装、不执行整机升级。支持 apt-get、apk、dnf、yum、zypper、pacman，要求 root 和 timeout。包管理操作最长 5 分钟。安装不使用当前交互终端；左侧独立日志视图约每秒刷新，可返回原终端或重新查看进度，关闭网页不会取消已下发的安装。
8. 安装日志只向任务所属账号且仍有服务器权限的后台会话返回。显示最近约 32 KiB，遮蔽软件源 URL 和常见凭据字段、移除控制序列；仅内存保留至任务过期，远程临时日志在结束后清理。失败显示网络、DNS、权限、空间、包管理器占用等原因；超时后先刷新核对，避免重复安装。
9. 保留后台登录、CSRF、同源 WebSocket、用户与服务器权限检查。面板保持不向其他账号开放；tmux 范围与该账号可操作的服务器系统用户一致。本次不扩展到 TG 网页终端，不改变其一次性授权和连接限时。
10. 本次只部署阿里，GitHub 源码／二进制不推送。不重置监控、账号、排序或通知数据。重启会中断面板保持任务，应在用户确认后执行。

文件管理与手机交互补充（custom-2026.10.11.7-ali 试用）
- 文件管理手机端全屏、电脑端侧栏可展开；顶部提供路径输入、上级目录、刷新、复制路径、上传和关闭。Esc 或关闭按钮只关闭文件连接，不中断 SSH。文件确认弹窗适配当前全屏容器。
- 打开时显示连接进度；创建／连接超过 15 秒或目录／传输 45 秒无进展显示超时，可重新连接。节点返回的具体错误会显示，原 Agent 对不可读目录仍可能退回用户主目录。
- 上传及重试前均确认目标路径和同名覆盖；进度只有收到节点完成响应才标记完成。取消、关闭或断线可能留下不完整文件，不自动删除或恢复同名旧文件；不支持断点续传。关闭传输时默认继续传输，须明确确认停止。
- 下载使用独立 Worker 顺序写入自己的临时文件，避免初始化竞态和重复下载同名短文件残留旧字节；不清空浏览器其他文件。当前 Agent 拒绝空文件下载时原样显示其错误，不声称已支持节点空文件下载。
- 手机快捷命令弹层显示时，终端和快捷键暂停输入；选中命令不执行，明确点击执行才发送，关闭后恢复焦点。手机会话按钮至少 44px，窄屏排序名称与操作分行，不改变排序逻辑或系统 ID。

tmux 窗口管理补充（custom-2026.10.11.8-ali 试用）
- 单个窗口时，窗口后面显示“添加窗口”；多个窗口时，各窗口后面显示“结束窗口”，另有“新增窗口”入口。结束后只剩一个窗口时立即切回“添加窗口”。最后一个窗口不允许单独结束，关闭整组请使用“结束会话”。
- 新增窗口只在指定会话内创建，不切换当前窗口、不关闭或保留其他普通终端；创建后点击窗口进入。窗口名最多 60 字，禁止控制字符。
- “结束窗口”确认后终止指定窗口的所有 pane 和任务，保留该会话的其他窗口。“结束会话”确认后结束整组窗口。“退出”只断开当前网页客户端连接，任务继续。
- 后台以节点 UUID、会话 ID/创建时间、稳定窗口 ID 校验目标，拒绝不存在、越权、已结束或共享到其他会话的窗口；执行前再次检查是否最后一个窗口。记录窗口名称及创建/结束请求和完成历史，不记录终端输入输出。并发外部 tmux 操作仍应刷新后核对。
- 窗口功能不配置开机自启，不保存或重放脚本命令。服务器重启不自动恢复任务。

TG 入口复用同一套终端、快捷命令、tmux 窗口及文件管理 UI；只通过独立的 TG 授权接口访问，不签发后台登录。TG 不提供面板保持，15 分钟授权过期即断开网页连接，tmux 任务不主动结束。详见 telegram-server-menu.md。手机／电脑的全屏按钮增加可访问名称，不支持全屏时提示使用横屏。
