# 图标库

图标设置保存在 SQLite 的 `logo_library_entries` 表；图像保存在 `data/logos`，由本站 `/api/v1/logo/assets/` 提供。备份时同时保留数据库和图像目录。

## 初始化与选择

首次启动从 `seed.json` 导入现有目录（2063 个运营商条目、2 个厂商条目；139 个条目附带 Logo）。参考目录不代表所有国家的全部在营运营商，也不是每个条目都有 Logo。已有服务器的厂商图标按图片去重收录，优先使用网站域名命名，可在图标设置修改名称。

初始化不改写服务器备注，也不自动把旧图片绑定到新条目。以后在服务器编辑器按名称、别名或网站搜索选择厂商；运营商可先选国家/地区再搜索。未收录的可在图标设置添加。

## 同步及删除

选择图标库条目时，备注同时保存 `logoLibraryId` 和图标快照。修改条目会在同一数据库事务中更新已关联服务器，并刷新运行时缓存；服务器保存时重新解析引用，避免旧表单覆盖最新图标。版本号检查防止并发覆盖。

删除条目会保留已关联服务器最后使用的图标，并解除引用。手动覆盖图片会解除引用；不自动改写原有独立图片。删除使用墓碑记录，重启不重新导入已删除条目。

## 安全与验证

修改接口仅管理员可用，并使用现有 CSRF 校验。远程图像导入复用 SSRF 防护及图片格式检查；访客只读取本站图像。`Seed` 幂等性、引用同步、删除快照、英文/中文字段、权限及并发版本由 Go 测试覆盖；前端包含名称搜索和桌面/移动端端到端测试。

## 厂商分组与卡片布局

厂商分组保存在 `logo_library_groups`；条目的 `groupId` 引用分组。新增、重命名、删除均限制管理员；删除分组把条目移到未分组，同时递增版本号，避免旧编辑表单重新引用已删除分组。服务器图标及备注不会因分组操作改变。

每台服务器可在 `providerLogo.logoLayout` 分别保存 `desktop` 与 `mobile` 的 `x`、`y`、`scale`。默认偏移 0px、缩放 100%，偏移范围 ±150px，缩放范围 25–250%；原始文本支持中文别名。更换图库图片保留服务器布局，图标库同步不覆盖布局。

Logo 独立定位，不参加卡片布局计算。电脑端以原到期进度条的 70px 区域居中，无到期时间时沿用同一定位基准；手机端保留 CPU—内存文字上方区域，默认最大 64×24px。名称、账单、进度条和指标位置不因添加 Logo 变化。

编辑器的同源 iframe 复用前台 ServerCard 及美化设置，通过验证 origin 和 source 的 postMessage 接收未保存的草稿，不通过 URL 或接口提交草稿。可实时切换电脑/手机预览，实时状态不可用时明确显示示例状态；只有保存服务器才持久化调整。
